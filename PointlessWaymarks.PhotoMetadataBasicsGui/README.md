## Photo Metadata Basics
            
This program is designed to help you set basic metadata and rename groups of photos.
            
## Background
            
For many years I was a happy Adobe Lightroom user, but eventually subscription cost increases outran my budget and willingness to pay for Lightroom 'forever'. So I moved on the On1 Photo RAW, which I really enjoyed, right up until it was time to put in metadata and rename photos... So I created this program to both fill the gap.
